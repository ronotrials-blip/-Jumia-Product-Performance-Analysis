Jumia Product Performance Dashboard

An Excel dashboard analysing pricing, discounts, reviews, and ratings across 112 Jumia Kenya product listings.

Built for the LuxDev Data Science & Analytics Programme — Week 1 Assignment.


Dataset

112 products · 57 with reviews · 723 total reviews · Columns: Product, Current Price, Old Price, Discount %, Reviews, Rating


What I Did


Cleaned the data — numeric formats, handled 55 missing rating/review entries, removed duplicates
Added three columns: Absolute Discount Amount, Rating Category (Poor/Average/Excellent), Discount Category (Low/Medium/High)
Built pivot tables analysing discount vs reviews, rating vs reviews, and top 10 products by discount and review count
Designed an interactive dashboard with charts, slicers, and KPI cards



Key Findings


Average price: KSh 1,187 · Average discount: 36.8% · Average rating: 3.89 / 5
Most expensive: 32PCS Portable Cordless Drill Set (KSh 3,750) · Cheapest: 3PCS Crochet Needle Set (KSh 38)
Products with 41–51% discounts attracted the most reviews — high discounts drive engagement
Higher-rated products (4–5 stars) account for the majority of all reviews
High discounts do not guarantee good ratings — some heavily discounted products have below-average scores



Tools

Microsoft Excel — Pivot Tables, Charts, Slicers, Conditional Formatting
